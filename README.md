## Idea central

> Un **patrón arquitectónico** organiza capas y dependencias.  
> Dentro se usan **patrones de diseño (GoF)** y **patrones de aplicación (Repository, DTO…)**.

## Fuentes

| Concepto | Origen |
|----------|--------|
| Categoría “patrón arquitectónico” | Buschmann et al. — *POSA* (MVC está en POSA; Hexagonal, Onion y Clean son posteriores) |
| MVC | Trygve Reenskaug (Smalltalk) |
| Hexagonal | Alistair Cockburn — *Ports & Adapters* |
| Onion | Jeffrey Palermo (2008) |
| Clean Architecture | Robert C. Martin (ensayo 2012; libro 2017) |
| Patrones GoF | Gamma et al. — *Design Patterns* (1994) |
| Patrones de aplicación | Fowler — *Patterns of Enterprise Application Architecture* (PoEAA) |
